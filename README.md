# Smart AI Assistant

A professional AI assistant built with Google Gemini and Streamlit.

## Features
- Multiple personality modes
- Model selection
- Temperature and token controls
- Document Q&A (PDF, DOCX, TXT)
- Chat export (TXT and Markdown)
- Usage statistics
- Professional UI

## Installation
pip install -r requirements.txt

## Environment Variables
Create a `.env` file:
GEMINI_API_KEY=YOUR_API_KEY_HERE

## Run
streamlit run app.py
